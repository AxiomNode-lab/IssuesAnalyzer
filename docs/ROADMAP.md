# Roadmap

## Phase 0 — validation
- Interview 10–15 contributors.
- Prototype one-URL report manually.
- Test whether reports change pursue/skip decisions.
- Define benchmark issues and label outcomes.

## Phase 1 — MVP
- Public issue analyzer.
- Deterministic score and evidence.
- GitHub sign-in and saved reports.
- Secure caching, observability, tests, and accessible responsive UI.

## Phase 2 — discovery
- Personalized search and filters.
- Daily/weekly opportunity digest.
- Change tracking and competition alerts.
- Team/community curated lists.

## Phase 3 — intelligence
- Calibrated time/complexity estimates.
- Optional issue explanation and contribution plan.
- External bounty adapters only where official APIs and terms permit.
- Maintainer-facing contribution-readiness dashboard.

## Exit criteria
Each phase advances only after measurable adoption and reliability criteria; feature volume alone is not success.
